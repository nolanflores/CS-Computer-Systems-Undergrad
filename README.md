# Bachelor of Computer Science
## Computer Systems Option - Oregon State University

This is a collection of assignments and labs from my tenure at OSU. I have collected these into one repository for my own ease of access after graduation. It also serves as a catalogue for me to show off works and progress over 4 years of college.

- I have placed each course into a directory named with the course number. I have created symlinks with more human readable class names that point to the numbered directories.
- Some of the assignments were done via github classroom. To avoid having nested repositories, I have deleted all .git/ subdirectories. There might still be residual effects, such as links in READMEs and .github/ folders that I missed.
